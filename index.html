I. Project Overview

The Major Project in CC 104 – Data Structures and Algorithms in JAVA is a group-based culminating project designed to allow students to apply the concepts, principles, algorithms, data structures, and programming techniques discussed throughout the course.

The project requires students to identify a real-world computing problem, propose an appropriate computing solution, and develop a functional Java-based application that demonstrates the appropriate use of:

  • Abstract Data Types (ADTs)
  • Data Structures
  • Algorithms
  • Searching and sorting techniques
  • Algorithm analysis
  • Iterative and/or recursive approaches
  • Abstraction
  • Encapsulation
  • Information hiding
  • Program testing and debugging
  • Appropriate programming and implementation strategies
The syllabus identifies the Major Project as an ADT-Based Problem-Solving System and requires students to develop and defend a functional application applying ADTs, data structures, algorithms, testing, debugging, and comparative evaluation.

II. General Project Objectives

  1. Identify and clearly define a real-world computing problem.
  2. Analyze the requirements of the identified problem.
  3. Select appropriate abstract data types and data structures.
  4. Design appropriate algorithms for the proposed solution.
  5. Implement the proposed solution using Java.
  6. Apply appropriate searching, sorting, tree, graph, list, stack, queue, set, map, or hashing concepts when applicable.
  7. Apply abstraction, encapsulation, and information hiding.
  8. Test and debug the developed application systematically.
  9. Analyze the efficiency and suitability of the selected algorithms and data structures.
  10. Explain and defend programming and design decisions.
  11. Work effectively as a member of a development team.
  12. Prepare technical documentation and communicate the completed project professionally.

III. Project Grouping

A. Group Composition

  • The project shall be completed by a group of students.
  • The instructor shall determine or approve the final group composition.
  • Each member must have a clearly defined responsibility.
  • All members are expected to contribute to analysis, design, implementation, testing, documentation, and presentation.

B. Individual Accountability

Although the project is completed as a group, individual performance will be evaluated. During the defense, any member may be asked questions regarding problem analysis, system design, data structures, algorithms, Java implementation, testing, debugging, complexity, design decisions, and individual contribution.

IV. Project Selection Guidelines

A. Choosing the Project

The proposed project must address a specific and realistic computing problem. Suggested areas include:

  • School or campus services
  • Library management
  • Inventory management
  • Student services
  • Appointment or scheduling systems
  • Transportation or routing
  • Small-business operations
  • Community services
  • Record management
  • File or document organization
  • Task or resource management
  • Searching and information retrieval
  • Ranking or prioritization systems
  • Other computing problems approved by the instructor
Important: The project should not simply be a generic CRUD application. The proposed system must demonstrate meaningful use of data structures and algorithms.

V. Project Requirements

  • Problem-Based: The project must begin with a clearly identified real-world problem.
  • Functional: The system must have working features and demonstrate actual processing of data.
  • Algorithm-Based: The system must use appropriate algorithms rather than relying entirely on built-in operations.
  • Data-Structure-Based: The project must demonstrate meaningful implementation or application of appropriate data structures.
  • Java-Based: The primary implementation language shall be Java.
  • Testable: The system must be tested using appropriate test cases.
  • Defensible: Students must be able to explain and justify their technical decisions.
  • Documented: The project must have complete technical and project documentation.

PART II – FINAL PROJECT DEVELOPMENT AND FINAL DEFENSE

XII. Purpose of the Final Project

The Final Project requires learners to transform the approved proposal into a functional Java-based computing solution.

The completed system should demonstrate the learners ability to:

  • Design appropriate data structures;
  • Implement algorithms;
  • Develop a functional Java application;
  • Test and debug the application;
  • Analyze implementation choices;
  • Apply abstraction, encapsulation, and information hiding;
  • Explain technical decisions; and
  • Communicate the completed project professionally.

XIII. Final Project Requirements

  • Functional Features: Core features must be operational.
  • Data Structure Implementation: Selected structures must be meaningfully applied.
  • Algorithm Implementation: Important algorithms must be implemented and explainable.
  • Searching and/or Sorting: Where appropriate, the system should demonstrate suitable techniques.
  • Testing: The group must demonstrate test cases and testing results.
  • Debugging: The group must identify and resolve significant errors encountered during development.
  • Efficiency Analysis: The group should explain efficiency and suitability of major algorithms and data structures.
  • Code Quality: The program should demonstrate organized code, appropriate naming, readability, modularity, encapsulation, appropriate comments, and maintainability.

XXI. Project Defense Rules

  1. All group members must be present during the scheduled defense unless an approved excuse is granted.
  2. All members must participate in the presentation and demonstration.
  3. Panel members may direct questions to any individual member.
  4. Each member must understand the complete project, not only their assigned component.
  5. The group must use professional and respectful language when addressing the panel.
  6. Students must answer questions honestly and clearly.
  7. Students must acknowledge the use of external libraries, references, code, or resources.
  8. Plagiarism, unauthorized copying, fabricated results, or misrepresentation of work is prohibited.

  11. Major project changes must receive instructor approval.

XXIII. Important Reminders to Students

The project is not simply a software-development activity. It is a Data Structures and Algorithms project.

The group must be able to answer:

  • What problem are you solving?
  • Why is your proposed solution appropriate?
  • What data structures are you using?
  • Why did you choose those data structures?
  • What algorithms are you using?
  • Why are those algorithms appropriate?
  • What is the efficiency of your solution?
  • How did you test and debug the system?
  • What alternative approaches could have been used?
  • What are the strengths, weaknesses, and trade-offs of your implementation?

The quality of the project will therefore be assessed not only by whether the program works, but also by the students' ability to analyze, design, implement, test, evaluate, document, and defend their computing solution.

XXV. Final Statement

The CC 104 Major Project is intended to provide students with an opportunity to demonstrate practical mastery of Data Structures and Algorithms in JAVA through a real-world computing problem.

Students are expected to demonstrate not only programming ability, but also problem analysis, algorithmic thinking, appropriate data structure selection, software implementation, testing, technical communication, teamwork, and professional presentation.

The Proposal Defense establishes the technical direction of the project, while the Final Defense demonstrates the completed solution and the students' ability to justify their technical decisions.

All groups are expected to work professionally, observe academic integrity, meet submission deadlines, and respond constructively to panel feedback and required revisions.
